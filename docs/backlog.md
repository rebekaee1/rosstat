## 2026-09-26 — Производительность под ботами: замеры и план пачек 2–3

**Инцидент.** Деплой `cd55001` (11:24 МСК) после FLUSHDB дал холодный кэш;
всплеск ботов держал соединения SEO-роутов idle-in-transaction → пул 5+10
исчерпан → 503 → автооткат на 12-й минуте watch. Фикс `7c076d4` (отпуск
соединения до ожидания кэша, пул 10+15, `pool_timeout` 3 с, деплой чистит
только `fe:*:ssr:*`) + `4bb32ae` выложены как `41539a9` (12:43 МСК), watch
зелёный. Trap — CONTEXT, Cold-cache pool exhaustion.

**Замеры (прод, 2026-09-26, read-only).**
- Один uvicorn-воркер = потолок 1 CPU, делит процесс с ~40 джобами планировщика;
  потолок ~14–16 запросов/с. Всплески 800–1100 запросов/мин дают провалы
  10–35 мин (03:40, 04:43–05:18, 08:31–08:49, 09:27–09:32, 11:11–11:27 МСК).
- Хост 4 vCPU / 7,9 ГБ: ~77% CPU простаивает, ~5,3 ГБ свободно — сервер больше
  не нужен, нужна параллельность.
- 278k запросов 03:00–12:35, ~85% боты (Googlebot, PerplexityBot ~1/3, Яндекс,
  Bing). Повтор URL 5–50% — кэш сам по себе всплески не лечит.
- Окна страницы страны грузят ~425k точек ради 12 значений (73 statement timeout
  за 2 дня, `/denmark`); `cat_siblings` мирового индикатора — ~2,5k полных строк
  ради 12; частичный индекс `ix_world_indicators_listed_signal` не используется
  (`.is_(True)` → `IS true`); главная без кэша 0,3 с; регион Техас холодный 12,2 с;
  OG держит сессию БД во время рендера.
- Redis 256 МБ полон, hit 29%, 1,1 млн evictions; SSR-страница 46–52 КБ без
  сжатия (zlib ~6,3×).
- Postgres: `pg_stat_statements` выключен, лимит контейнера 2,5 ГБ,
  shared_buffers 640MB, jit on; дубль-индекс `ix_world_data_points_indicator_date`
  471 МБ; остатки `fe_sync_*_20260924` ~1,6 ГБ. В логе nginx нет `$request_time`.
- ETL 06:00/20:00: 107 из 117 загрузок с ошибкой — диагностируется отдельно.

**Пачка 2 (ветка `perf-batch2`, в работе):** web 3 воркера + планировщик
отдельным процессом; переписать запросы окон страны и `cat_siblings`; починить

сжатие SSR-кэша; тяжёлые джобы вне event loop; `$request_time` в nginx.

**Пачка 3 (ждёт окна, ~1 мин рестарта БД):** память/настройки Postgres +
`pg_stat_statements`; `DROP` `fe_sync_*_20260924` и дубль-индекса.

**Не нужно:** сервер больше; пре-генерация 5 млн статических страниц;
