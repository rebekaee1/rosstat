# ADR-0021: Сторож свежести рядов и правило «один показатель — один смысл» для остановленных дублей

**Status:** Accepted для кода ветки `circle12/int` (коммиты DATA `d8e147fd`, `a324742f`, `a5a87cb8`, `81fbf017`, `10b3a7c3`) по заданию владельца 12.10.2026 («данные устаревают, а мы узнаём от людей»); **не выпущено**, сторож по умолчанию выключен, скрипт снятия дублей с листинга на базе не запускался.
**Date:** 2026-10-12.
**Part of:** [`../data-contracts.md`](../data-contracts.md#c12-2026-10-12), [`../workflow.md`](../workflow.md#circle12-2026-10-12), [`../knowledge-unknowns.md`](../knowledge-unknowns.md).
**Related:** [ADR-0011](0011-world-eurostat-data-plane.md) (плоскость данных Евростата, карантин структуры), [ADR-0012](0012-world-multi-provider-official-first-forecasts.md), [ADR-0013](0013-country-first-url-architecture.md) (301 и canonical).
**Code anchors:** `backend/app/services/freshness.py`, `backend/app/tasks/freshness_watchdog.py`, `backend/app/api/system.py` (`/health/freshness`), `backend/app/data/world_superseded.py`, `backend/app/data/legacy_redirects.py` (`resolve_world_superseded`), `backend/scripts/unlist-superseded-world.py`, `backend/scripts/audit-freshness.py`, `backend/app/services/base_parser.py` и `http_client.py` (сбой сети не `parsed_zero`), `backend/app/data/eurostat_headline.py` (закрепления срезов).

## Контекст

Аудит 12.10.2026: Россия свежая (81 из 104 публичных рядов свежие, 20 с лагом, 3 просрочены), а в мире 22 464 из 278 882 публичных рядов (8,1 %) старше порога: 6 511 из-за замороженного среза Евростата (переход на базу 2021=100), 13 327 отстающие страны, 2 283 из наборов, которых уже нет в оглавлении Евростата, 298 закрытых, 31 остановленный дубль. Значок «Устарело» (круг 11) показывает проблему читателю, но владелец о ней не узнавал. Ложный сигнал в обратную сторону: 09.10 «Zero-parse» у топлива и недельной инфляции был сбоем сети, а не сменой вёрстки Росстата.

## Решение

1. **Сторож** `freshness_watchdog` (10:30 МСК, `locked_job`, флаг `RUSTATS_FRESHNESS_WATCHDOG_ENABLED`, по умолчанию `false`) считает просроченные публичные ряды тем же правилом, что клиентский `dataFreshness.js` (тест сверяет константы), по источникам и причинам, и шлёт ОДНО сообщение, если просрочено не меньше `RUSTATS_FRESHNESS_WATCHDOG_MIN_STALE` (25) и состав изменился по порядку величины либо прошла неделя. Сводка по запросу: `GET /api/v1/health/freshness` под токеном аналитики.
2. **Остановленный дубль не выдаётся рядом с живым.** Список `world_superseded.py` (`prc_hicp_cind/cann/cmon` → `prc_hicp_minr`): 301 на листингованную карточку канона той же страны, `redirect_to` в API, исключение из поиска и из повторного листинга; из каталога и sitemap карточки снимает отдельный скрипт после проверки (не миграция). Без живого канона страница остаётся.
3. **Сбой источника ≠ пустой разбор.** Сетевой сбой прогона помечает статус `failed` «Source unreachable»; потолок времени ежедневного ETL (`RUSTATS_ETL_JOB_MAX_SECONDS`) пропускает остаток и называет его в итоге.
4. **Закрепление срезов** пяти наборов Евростата, вышедших из карантина структуры, в `eurostat_headline.py`.

## Последствия

- **Плюс:** владелец узнаёт о массовой просрочке одним сообщением, а не от посетителей; ложное «смена layout» не рассылается; читатель не видит двух карточек одного показателя, одна из которых остановлена.
- **Цена:** первое сообщение будет большим (на 12.10 — около 22 тыс. рядов), дальше только изменения и недельное напоминание; список дублей ведётся вручную.
- **Не решено (на 2026-10-12):** 6 511 рядов Евростата на новой базе 2021=100 (`sts_*`, `ei_*`, `isoc_ciegi_ac`; 61 набор) — отдельная работа DATA2, не в этой ветке; 72 набора, которых нет в оглавлении Евростата (2 283 ряда), — решение редактора; сторож и правило дублей не выкладывались, 301 и API проверены на SQLite, не через nginx/Caddy; нет значка «Актуальные данные» на странице устаревшего ряда без дубля.
