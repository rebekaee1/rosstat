# ADR-0015 — Каталог официальных региональных рядов BEA для США

- **Status:** Accepted
- **Date:** 2026-09-24
- **Part of:** [ADR-0014](0014-subnational-regions-generic.md), [источники данных](../data_sources.md)

## Контекст

Паспорт FRED/BLS из ADR-0014 даёт небольшой набор базовых показателей по
штатам. Для широкого покрытия BEA публикует машиночитаемые региональные ZIP
архивы с полной историей, в том числе доходы, ВВП и потребление по отраслям.
API BEA требует ключ, а официальный ZIP доступен без него.

## Решение

Статический каталог `world_bea_regional/us.json` перечисляет опубликованные
линии BEA из семи архивов и таблиц текущей классификации. `build-us-bea-catalog.py`
отбирает линии с общенациональным рядом и покрытием минимум 45 штатов/округа,
удаляет точные повторы и полностью нулевые линии, требует известного русского
названия и единицы. Исключённые после пересмотра каталога линии снимаются с
публичного листинга, а их прежние наблюдения сохраняются для аудита.
Код линии и таблицы сохраняется в стабильном публичном коде. Новые линии
публикуются только после обновления каталога; новые значения и пересмотры
поступают автоматически.

Загрузчик `world_bea_regional.py` читает официальные ZIP, сверяет диапазон
истории и географическое покрытие, обновляет общенациональный ряд и 51
региональный ряд в одном контуре. Хэш ZIP вместе с метаданными каталога
позволяет пропускать неизменившийся выпуск. Загрузка каждого архива
транзакционная, а сбой выпуска виден планировщику. Исторические классификации
отраслей не объединяются с текущими сериями.

Большой каталог требует одного пакетного запроса последних точек в профиле
штата и SSR. Поиск показывает порциями по 120 результатов; карточки доступны
по прямым URL и через разделы каталога. Ранг штата не рассчитывается на
профиле для каждой линии BEA, чтобы избежать тысяч запросов по 51 территории;
на отдельной карточке показателя сравнение штатов остаётся доступным.
Верхние карточки профиля выбираются из `featured_indicators` паспорта страны,
чтобы в обзоре оставались базовые ВВП, труд, доходы и жильё.

## Навигация по каталогу США

На страницах США и штатов 48/45 исходных разделов сведены в восемь крупных
тем: ВВП и производство; труд и зарплаты; доходы и потребление; цены; бюджет,
налоги и соцвыплаты; население и жильё; бизнес и отрасли; финансы и рынки.
Второй уровень сохраняет исходные разделы и стабильные URL каждого ряда.
Пустые темы скрываются; в профиле штата строки без опубликованных значений
не считаются доступными. Клиентский маппинг привязан к стабильным кодам таблиц
BEA (`usCatalogTopics.js`), а не к переводимым названиям. Каталоги России и
европейских стран не используют эту группировку.

Русские названия линий проверяются в `description_ru.json`, подписи таблиц —
в `build-us-bea-catalog.py`. Обновление `us.json` не меняет английские названия
или данные. Для немедленной публикации изменённых метаданных без перезагрузки
миллионов точек есть `backend/scripts/refresh-us-bea-metadata.py`; очередная
загрузка ZIP всё равно сверяет исходные наблюдения и пересмотры.

## Границы

BEA не покрывает всю экономику США: текущие данные рынка труда BLS,
демографию Census и цены жилья FHFA продолжает вести отдельный паспорт.
Название и методология BEA сохраняют единицу, периодичность и первоисточник;
темы сверяются с `Name` в архивных `__definition.xml`;
пропуски источника остаются пропусками. Этот контур не меняет данные регионов
России. Прогнозы национальных рядов BEA допускаются только после отдельной
проверки качества модели на истории; отраслевые ряды не получают прогноз
автоматически по одному факту наличия данных.
