# Планета: устройство и локальная приёмка

Срез на **2026-09-30**. Планета подключена в SPA на главной и в мировом рейтинге.
Светлая сцена и обновлённый путь выбора/сравнения проверены локально в браузере.
В текущем `scripts/check-all.sh` прошли 3062 backend-теста (9 пропущено),
1003 frontend-теста, ESLint и build. После последней правки фокуса повторены
все frontend-проверки. Служебные карты регенерированы; guards проверены отдельно.
Мобильная компоновка повторно проверена при CSS viewport 360 × 844 и coarse pointer.
Деплой, production-приёмка и FPS не проверялись.

## Файлы и границы ответственности

| Файл | Ответственность |
| --- | --- |
| `frontend/src/components/PlanetView.jsx` | Поиск и год, список стран, карточка наблюдения, пара для сравнения, Земля/данные, SVG fallback, retry, легенда и credit |
| `frontend/src/components/PlanetView.css` | Размер сцены, панель страны, мобильная компоновка, reduced motion |
| `frontend/src/components/PlanetScene.jsx` | Lazy WebGL/R3F-сцена, текстуры, камера, raycast, растровый атлас границ и освобождение ресурсов |
| `frontend/src/lib/planetShaders.js` | Мягкое иллюстративное освещение от камеры, поверхность, океан, облака и атмосфера |
| `frontend/src/lib/planetGeometry.js` | Привязка геометрии к каталогу, алиасы, координаты, центры стран, bounds для picking и критерий детализации |
| `frontend/src/lib/planetNavigation.js` | Адаптация камеры к viewport, бюджет DPR/GPU; различение tap, drag, cancel и нескольких касаний |
| `frontend/src/components/home/HomeWorkbench.jsx` | Годовой срез, полный рейтинг и benchmark главной; начальный режим Земля |
| `frontend/src/pages/WorldRatingPage.jsx` | Данные мирового рейтинга; начальный режим данных |
| `frontend/public/planet/` | Локальные текстуры, источник, лицензия и SHA-256 manifest |

Three.js/R3F загружаются отдельной lazy-сценой. HTML-поиск и карточка страны не
зависят от GPU. `WorldMap` остаётся автоматическим аварийным fallback.
3D-canvas работает на клиенте; существующий backend SSR не следует считать
проверенным по факту успешного запуска canvas.

Новый backend API, polling и серверная отрисовка планеты не добавлены. Данные
приходят через существующие запросы родителей, а текстуры и atlas chunks —
локальные статические файлы с действующим HTTP-кэшированием. Первый холодный
визит всё ещё передаёт эти файлы; локальный URL не отменяет передачу по сети.

В текущей production-сборке `PlanetScene` занимает **260 560 байт gzip**,
общий `external-store` shim — **1 106 байт gzip**. Ранее общий shim затягивал
в lazy-зависимости сцены Recharts; теперь `charts` не входит в эту цепочку.
Исключено примерно **120 000 байт gzip** лишнего JavaScript с пути запуска
планеты. Это размеры готовых `.gz` файлов локального build, а не измерение
скорости сети; общие React/d3/код страницы сюда не включены.

## Контракты

- Единая верхняя панель содержит поиск страны, выбор года и один переключатель
  «Земля / Данные». Ручного выбора SVG-карты и autoplay-таймлайна нет. Главная
  передаёт весь рейтинг без прежнего ограничения 32 строк и не дублирует его
  отдельным блоком ниже планеты. Вместо пустой боковой подсказки всегда доступен
  список стран; выбранная карточка компактная, на телефоне находится перед сценой.
- Родители передают `years`, `year`, `onYearChange`, `conceptSlug`, `rankingItems`,
  `benchmark` и `ratingHref` вместе с существующими данными. Для мирового рейтинга
  `rankingItems` содержит места базового показателя: сортировка дополнительной
  колонки таблицы не должна подменять этот показатель. Новых API-запросов нет.
- `countries` — публичные строки каталога; `valuesByCode` и `detailsByCode` могут
  быть `Map` или объектами. Страна из среза с действующим `country_slug` сохраняется
  в поиске, даже если ещё отсутствует в переданном каталоге.
- Географический код нормализуется отдельно от API-кода: `UK → GB`, `EL → GR`,
  числовые идентификаторы атласа сопоставляются ISO. Для чтения значений и перехода
  сохраняется исходный `country.code`. Чтение сначала проверяет точный API-код,
  затем алиас: существующий `UK` не заменяется ключом `GB`.
- Поиск, строка списка и поверхность планеты выбирают одну и ту же страну,
  выделяют её и показывают карточку без перехода. Навигацию выполняет
  явная кнопка карточки через `onSelect(country, detail)`; при наличии
  `indicator_code` используется действующий маршрут показателя этой страны.
- Значение `0` является данными. Отсутствие значения не превращается в ноль;
  карточка показывает отсутствие наблюдения. Дата и источник берутся из строки
  выбранной страны, единица — из выбранного показателя.
- Название benchmark берётся из серверного `benchmark.label`: среднее нельзя
  подписывать как медиану. Пока данные главной загружаются, skeleton не выдаёт
  ещё не полученные наблюдения за отсутствие данных.
- Изменение года обновляет значения, цветовой слой, рейтинг, benchmark и карточку
  выбранной страны. Смена «Земля / Данные» и кнопка обзора сохраняют выбор;
  отдельный крестик очищает его. Поиск доступен мышью и клавиатурой; Enter
  закрывает список после выбора.
- Ссылка полного рейтинга главной сохраняет выбранный год, например
  `/world/rating/gdp-usd?year=2024`; на странице рейтинга ведёт к `#rating-table`.
  Кнопка «Все показатели» открывает существующую страницу выбранной страны.
- Для сравнения закрепляются максимум две страны одного `conceptSlug`.
  Ссылка имеет вид `/compare?codes=w:germany:gdp-usd,w:france:gdp-usd`
  (параметр кодируется через `URLSearchParams`). Это действующий формат
  ComparePage; национальный `indicator_code` в него не подставляется. Пара
  доступна гостю. Закрепление требует реального значения выбранного года,
  включая `0`; российский каркас без наблюдения не создаёт ряд для сравнения.
  После первой страны явная кнопка выбора второй переводит к поиску; каждая
  страна удаляется из пары отдельно. При двух закреплённых странах третья
  не заменяет их молча: карточка объясняет, что нужно сначала освободить место.
- В режиме данных раскрываемая легенда показывает числовые интервалы каждого
  цветового диапазона, единицу и отдельное обозначение отсутствия данных.
- `+Y` — север, `+Z` — longitude 0, `+X` — 90° восточной долготы. Поворот
  `SphereGeometry` на `-π/2` вокруг Y согласует UV с equirectangular-текстурами и
  атласом. После изменения UV обязательно проверить береговые линии и picking.
- Raycast идёт по видимой поверхности Земли; атмосфера и маркер не принимают
  попадания. Drag, возвращающийся в исходную точку, отменённый жест и несколько
  одновременных касаний не превращаются в выбор страны.
- Геометрия стартует с уже доступного `WORLD_FEATURES`: границы всех его стран
  видны с первого кадра независимо от наличия экономических данных. После первого
  показа дневной поверхности в idle подгружается `countries-50m.json`;
  при отсутствии `requestIdleCallback` используется короткая отложенная загрузка.
  Save-Data пропускает эту фоновую детализацию. `countries-10m.json` загружается
  при выборе страны, отсутствующей в текущем атласе, или страны площадью менее
  приблизительно 4 870 км². Обычный выбор Германии/Британии не запрашивает 10m.
  Детализация повышается монотонно: поздняя
  загрузка 50m не должна перезаписать уже полученный 10m. Границы принадлежат
  `world-atlas`/Natural Earth, а покрытие экономическими данными — API каталога.
  Текущие локальные atlas chunks: 50m — **230 257 байт gzip**, 10m —
  **920 134 байта gzip**; оба promise кэшируются между экземплярами сцены.
- Picking предварительно проверяет кэшированные географические bounds, включая
  пересечение ±180°, и только затем вызывает `geoContains`. Hover/выбор обновляют
  отдельный 1024 × 512 слой из нужных полигонов: полный 2048 × 1024 слой границ
  не перерисовывается при каждом выборе. Мягкий бирюзовый fill сохраняет текстуру,
  контур с белым halo компонуется поверх облаков.

`frameloop="demand"` ограничивает отрисовку изменениями сцены и камеры.
Автовращения нет; фокус камеры длится 250 мс, reduced motion убирает перелёт.
Текстуры, оба atlas texture, геометрия, OrbitControls и listeners освобождаются при
размонтировании; поздно завершившиеся загрузки тоже освобождают свои текстуры.
Ошибка дневной текстуры, WebGL или потеря контекста переключает на SVG, сохраняя
выбор. Ошибка необязательной packed map оставляет уже загруженную Землю рабочей.
Retry создаёт новый lazy-тип сцены: повторный mount того же отклонённого
`React.lazy` promise не является повторной загрузкой.

На coarse pointer вращение сначала выключено: canvas использует
`touch-action: pan-y pinch-zoom`, чтобы страница прокручивалась. Кнопка
«Вращать / Готово» явно включает и завершает управление планетой; активный режим
передаёт вращение и pinch камере. Колесо мыши на desktop прокручивает страницу,
масштаб планеты меняют кнопки. Расстояние камеры учитывает меньший угол обзора
viewport; узкая сцена не должна обрезать глобус. При ручном приближении камера
может показать участок поверхности; обзор снова помещает весь диск в сцену.

## Изображения и лицензия

Источник — [официальный Earth example Three.js](https://threejs.org/examples/webgpu_tsl_earth.html),
с текстурами [Solar System Scope / INOVE](https://www.solarsystemscope.com/textures/),
переработанными на основе NASA. Лицензия —
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Видимый credit со ссылками
и отметкой адаптации находится в `PlanetView`; README не заменяет этот credit.

Это архивные композиции с художественной обработкой. Мягкий источник дневного
освещения следует за камерой с небольшим верхним боковым смещением: видимая
поверхность остаётся читаемой при вращении. Это иллюстративное освещение атласа,
а не текущий солнечный терминатор. Облака не показывают текущую погоду. Bump меняет
освещение поверхности, не создаёт настоящий горный рельеф.

| Этап | Файл и разрешение | Передача |
| --- | --- | --- |
| Первый реальный кадр, все устройства | `earth_day_2048.webp`, 2048 × 1024 | 263 130 байт |
| Необязательные облака/материал после day | `earth_material_512_4dfa031876a1.webp`, 512 × 256 lossless | 186 426 байт |
| Полный текущий набор | Два файла выше; night/4K не запрашиваются | 449 556 байт |
| Save-Data | Только day, без packed | 263 130 байт |

Первый кадр не ждёт packed map: шейдер начинает с нейтрального материала 1 × 1.
Прежние runtime-наборы передавали 2 248 543 байта на desktop и 1 136 358 байт
на compact. Текущий полный набор меньше приблизительно на 80% и 60%
соответственно; первый day — только часть общего запуска. Эти числа исключают
JavaScript, геометрию и HTTP-заголовки, время загрузки ими не доказано.

Day использует `SRGBColorSpace`; packed map — `NoColorSpace`:
**R = bump, G = roughness, B = clouds**. Не выполнять sRGB/profile-преобразование
packed map. Точные URL, SHA-256, размеры и рецепты производных файлов —
[`source-manifest.json`](../frontend/public/planet/source-manifest.json), подробная
атрибуция — [`README.md`](../frontend/public/planet/README.md).

Runtime URL имеют вид `/planet/earth_day_2048.webp` и обслуживаются самим сайтом;
новая packed map содержит hash в имени. Её lossless RGB декодирование проверено
сравнением с Lanczos derivative. Исходные night/4096 файлы сохранены для происхождения
и возможных будущих производных, но не участвуют в загрузке сцены.
Существующий static location в `frontend/nginx.conf` принимает JPG/WebP; Vite
копирует `frontend/public/planet` в build. Не переносить загрузку обратно на
внешний CDN и не считать локальные URL гарантией работы первого визита offline.

Пиксельная плотность ограничена: desktop — максимум 1.5, compact/coarse pointer —
1.25; `deviceMemory ≤ 4` или Save-Data — 1. Сфера использует 96 × 64 сегмента
на обычном desktop и 64 × 48 на compact/ограниченном устройстве.

Расчёт RGBA8 памяти текстур с mipmaps даёт приблизительно 10.67 MiB для day и
0.67 MiB для packed. Два atlas texture без mipmaps добавляют 8 MiB и 2 MiB:
суммарно около **21.34 MiB**. Это арифметическая оценка по размерам,
исключающая framebuffer, геометрию и накладные расходы драйвера. Измерения памяти
GPU, нагрева и батареи на устройствах не проводились.

desktop-браузере, мобильной эмуляции и локальном Vite preview готовой сборки
с реальными данными доступного API. Для RU preview прокси направлен на
`https://ru.forecasteconomy.com`: production-сборка не использует dev-переключатель
локали API. Эти проверки не подтверждают production
или производительность реальных телефонов.

Для повторения открыть `/` и `/world/rating/gdp-usd` локально, использовать
реальные данные API и обе локали. Сбой текстуры проверять сетевой блокировкой
точного текущего day URL; затем снять блокировку до Retry. После проверки вернуть
viewport и сетевые настройки браузера.

При смене `preview_locale` на одном localhost выполнить перезагрузку без HTTP-кэша:
наблюдался ответ прежней локали из disk cache (`Vary: Host`), несмотря на новый
`X-FE-Locale`. Проверка обеих локалей выполнялась с обновлёнными ответами API.

Фокусные автоматические проверки из `frontend/`:

`planetNavigation.test.js` содержит 23 проверки подгонки камеры, бюджета рендера
и pointer-жестов; `planetGeometry.test.js` — 31 проверку, включая выборочную
загрузку fine atlas и сверку bounds picking с exhaustive `geoContains`.
Моки сцены в компонентных тестах проверяют HTML-контракт, а не GPU-рендеринг.
При дальнейших изменениях прогнать общий `./scripts/check-all.sh` и повторить
desktop/mobile сценарии после последней правки.

## Ещё не принято

Реальные iPhone/Safari и Android/Chrome: плавность, GPU-память, нагрев, батарея,
context loss/restoration, жесты и длительные сессии пока не проверены. Эмуляция
CSS viewport не заменяет телефон. Не заявлять FPS или готовность для слабых GPU
до измерений на устройствах. После возможного деплоя отдельно проверить nginx,
JPG/WebP Content-Type, lazy chunks, credit и маршруты на production.
