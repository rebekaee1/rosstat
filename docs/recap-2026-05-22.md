Звонок 21 мая (правки T1-T12 / P0-P2)

T1 / №1 — Cmd+K поиск. Заменён узкий inline-инпут в Navbar на command-palette modal по центру экрана. Хоткей Cmd+K (Ctrl+K), `/` если фокус не в инпуте, ↑↓ навигация, Enter — открыть, Esc — закрыть, click на backdrop — закрыть. Кнопка в навбаре — только иконка лупы (так меню не съезжает на средних экранах). Проверь: нажми Cmd+K где угодно, должен открыться modal по центру.

T2 / №2 — объединение карточек ставок. Кредиты юрлицам, кредиты физлицам, вклады физлиц — три семьи с переключателем срока «До 1 года / 1-3 года / Свыше 3 лет» через VariantGroupPicker. Primary одна на семью, medium/long скрыты из листинга. Имена обобщены: «Ставка по кредитам юридическим лицам» (без срока в названии). Проверь: открой `/indicator/credit-rate-corp-short`, увидь pill-переключатель срока; аналогично `/indicator/credit-rate-ind-short` и `/indicator/deposit-rate`.

T3 / D5 — split категории «Финансы». Новая категория «Валюты» (slug=currencies): usd-rub, eur-rub, cny-rub. Иконка `CircleDollarSign` (как просил «поменять на иконку доллара»). Старая «Финансы» → «Деньги и бюджет»: денежные агрегаты, резервы, кредиты, бюджет. categories.js и seo_content.py::CATEGORY_META синхронны как требует ADR-0003.

T4 / №13 — склейка дублирующих карточек. Один показатель — одна карточка в листинге; варианты доступны через VariantGroupPicker. 6 новых variant-групп: ИПП, безработица, зарплата, экспорт/импорт, текущий счёт. 10 кодов в INDICATOR_HIDDEN_FROM_LISTING.

T5 / №16 — ИПП по умолчанию открывается в режиме г/г. Редирект `/indicator/ipi` → `ipi-yoy`; flagship категории «Бизнес» синхронизирован. (Был стёрт при Phase 1 refactor 22-05, восстановлен при ревизии через `DEFAULT_REDIRECTS` в IndicatorDetail.jsx.)

T6 / D3 — hero как YoY%. Для индексных индикаторов (IPP, PPI, housing-price-primary/secondary) hero-карточка показывает изменение год к году в %, а не уровень индекса (raw 105.2 — бессмысленный без контекста). Реализация через schema-поля hero_value/hero_unit/hero_label + model_config_json.hero_view = "yoy_pct".

T7 / E1 — bulk_upsert не затирает БД None'ом. Если парсер вернул пустой/None payload — существующая точка сохраняется. Регрессионные тесты в test_upsert.py: empty list, None value, partial short payload, mixed None+value. Это укрепление инварианта из ADR-0002.

T8 / A3 — list_indicators фильтрует is_listed=True по умолчанию. Counterpart-индикаторы (exports-monthly, gdp-real-yoy и т.п.) перестают дублировать primary в каталоге. Параметр `?include_unlisted=true` для search'а и админ-обхода.

T9 / D2 — длинные SEO-блоки. Новый компонент IndicatorSeoBlocks рендерит indicator.seo_blocks из БД (поле использовалось только в SSR). На момент ревизии заполнено для 11 индикаторов: budget-deficit, cpi, deposit-rate, exports, gdp-nominal, housing-price-primary, ipi, key-rate, unemployment, usd-rub, wages-nominal (по 2-4 блока на каждый). Длинный читаемый контент для Google + полезный для пользователя. Топ-30 — задача в plan.md. Проверь: открой `/indicator/cpi` — должны быть содержательные текстовые секции под графиком.

T10 / C2 — зарплата как индекс. Derived `wages-index` (base 2015=100) через новую чистую op `rebase_to_index(series, base_year)`. Позволяет сопоставлять с housing-price-* по той же базе.

T11 / C1 — индекс доступности жилья. Derived `housing-affordability` = (wages-index / housing-price-secondary) × 100. Значения >100 — зарплаты росли быстрее цен на жильё с 2015, <100 — наоборот.

T12 / B1 — ключевая ставка с 1992. Backfill через `scripts/backfill-keyrate-history.py`: 85 точек ставки рефинансирования 1992-01-01 → 2013-09-12 с официального cbr.ru. Дальше существующий cbr_keyrate_html парсер. Methodology у key-rate упомянута склейка; validation max расширен с 60% до 250% (в 1995 ставка достигала 200%). Проверь: `/indicator/key-rate`, выбери timeframe «Всё» — должен начинаться с 1992.

D6 — RUONIA daily без разрывов. connectNulls на Line/Area для daily-графиков — выходные и праздники не разрывают линию.

D4 — Live Ticker первая версия. Над Navbar 6 котировок (USD/EUR/CNY/key-rate/RUONIA/gold). Удалена утром 22 мая (не соответствовала договорённости).

B3 — history audit. `scripts/audit-indicators-history.py` пробегает по всем активным, выводит markdown-таблицу (count, first_date, last_date) + кандидатов на backfill (история короче 2010).

C4 — research backlog. ~15 потенциальных индикаторов для будущего: RUONIA по срокам, MosPrime, NFEA Swap Rate, OFZ Curve, доходы федбюджета по статьям, электропотребление, грузооборот, Urals, реальные доходы, серебро/платина/палладий.

C3 — deposit-rate по сроку. deposit-rate-medium (1-3 года, CBR DataService pub=18, ds=37, el=9), deposit-rate-long (>3 лет, el=10). Существующий deposit-rate как «короткие» (до 1 года, el=7). На момент ревизии у medium/long было 0 точек данных (парсер не дотриггерился после deploy) — отыграл вручную через `run_etl_for_indicator`, сейчас у всех трёх 147 точек 2014-2026 (avg short=8.12%, medium=8.83%, long=7.36%). Проверь: `/indicator/deposit-rate`, переключатель срока — все три pill'а должны рисовать графики.

Ассеты в /assets/ остаются с max-age=31536000, immutable. Это закрывает Asset-hash trap из AGENTS.md.

Звонок 22 мая, день (Phase 1-5 + ticker + search всё доделать)

Phase 1 — Trade unification. 11 trade-индикаторов сжаты до 6 родительских карточек: exports, imports, services-exports, services-imports, trade-balance, current-account. Их derived'ы (yoy %, qoq %, yoy_abs, mom %) — режимы in-page, не отдельные карточки.

Новая чистая op `yoy_abs(series)` — разница в единицах источника к 12 мес назад. Назначение — balances со знаком (trade-balance, current-account), где процент YoY бессмыслен (база меняет знак). DERIVED_SPECS пополнен `trade-balance-yoy-abs` и `current-account-yoy-abs`. Старый `current-account-yoy` (%) помечен `is_active=false` — депрекейтнут.

`applyMoMTransform` — клиент-side виртуальный transform MoM% для monthly counterparts (exports-monthly, imports-monthly, services-*-monthly) без backend derived. Изоляция от forecast-пайплайна. Проверь: `/indicator/exports` — переключатели Уровень/YoY%/QoQ%; `/indicator/exports-monthly` — Уровень/MoM%.

Phase 2 — Labour market. wages-nominal унифицирован в карточку «Средняя заработная плата» с режимами Номинальная / Реальная / YoY % / Индекс 2015=100. Derived wages-real, wages-index, wages-yoy скрыты из листинга. Аналогично unemployment: Месячно / Квартально / 12М среднее. Проверь: `/indicator/wages-nominal`, должен быть переключатель из 5 режимов.

Phase 3 — Housing. housing-price-primary и housing-price-secondary получили режим YoY % (через derived housing-yoy-{primary,secondary}). housing-yoy-* скрыты из листинга.

Phase 4 — Rates renaming. credit-rate-corp-short, credit-rate-ind-short, deposit-rate переименованы на общие имена (без срока), term split полностью через VariantGroupPicker. Имена в БД и в SEO синхронны.

Phase 5 — Daily aggregation. `applyAggregateTransform` — клиент-side bucket-average для daily-индикаторов (key-rate, ruonia, cbr-fx-usd, cbr-fx-eur, cbr-fx-cny, gold-price, brent, btc-usd). Режимы Ежедневно / Понедельно / Помесячно / Поквартально / Годово. Backend derived не заводим. Проверь: `/indicator/key-rate`, переключатель Ежедневно/Понедельно/.../Годово.

Live Ticker (после grill-me). 5 котировок по договорённости: USD/RUB, EUR/RUB, CNY/RUB, BTC/USD, Brent. Источники: MOEX ISS (CETS-борд для FX, FORTS с динамическим выбором ближайшего фьючерса BR-X.Y для Brent), Binance public (BTC/USDT), CBR XML_daily fallback для FX. Сейчас по факту через CBR идут USD и EUR (MOEX CETS отдаёт LAST=null — у USD редкие сделки, EUR_RUB__TOM фактически мёртв после санкций ЕС март-2024), CNY и Brent живые с MOEX, BTC живой с Binance. Когда MOEX вернёт цену — автоматически переключится без правок. APScheduler job interval 5s кладёт TickerSnapshot в Redis с TTL 30s, frontend polling 4s через useQuery. BTC/USD и Brent — также полноценные indicator-страницы: Binance klines 1500 дней, Yahoo Finance BZ=F с 2015. Проверь: ticker над Navbar — все 5 значений с дельтой, цвет и шрифт одинаковые. CNY/RUB и BTC должны тикать живо, USD/EUR/BRENT обновляться при изменении источника.

Search показывает все индикаторы. useIndicators({ includeUnlisted: true }) пробрасывается до API. На «экспорт» поиск отдаёт все 6 trade-карточек (товары/услуги, monthly/quarterly, yoy %, qoq %), а каталог остаётся витриной из 6 родительских.

Ревизия 22 мая, вторая половина (после твоих новых критик)

Search synonyms через seo_keywords. Substring «зарпл» возвращал только wages-yoy («Зарплаты (изм. г/г)»), потому что корня «зарпл» нет в «Средняя заработная плата». Фикс: добавил seo_keywords в IndicatorSummary schema → в haystack search'а. У всех 5 wages в seo_keywords есть «зарплата» → все 5 находятся. Универсально: «инфля» → все cpi/ипц, «безраб» → все unemployment-*. Проверь: Cmd+K → «зарпл», должно быть 4-5 результатов.

wages-nominal-annual sibling. Я залил 24 годовые точки 1991-2014 в wages-nominal (frequency=monthly), и chart label оставался «ПОМЕСЯЧНО» с рваным рядом. Это annual-in-monthly mixing trap. Фикс: создал отдельный wages-nominal-annual (frequency=annual, is_listed=false), перенёс точки, в viewModeFamilies добавил пятый режим «Годовое (с 1991)». wages-nominal снова чисто monthly с 2015. Проверь: `/indicator/wages-nominal`, последний пилл «Годовое (с 1991)» — переключи, увидь годовой график 1991-2014 (label на нём «годово», не «помесячно»).

Числа wages 1991-2014 сверены 1:1 с публичным Росстат XLSX «Среднемесячная номинальная начисленная заработная плата работников в целом по экономике РФ 1991-2024 гг.» (29.05.2024). Все 24 точки совпадают до округления. Ссылка прописана в шапке `backend/app/data/wages_historical.py`.

CONTEXT.md дополнен trap'ом Annual-in-monthly mixing. AGENTS.md чеклист «новый индикатор» расширен с 6 до 7 пунктов — добавлен критичный Frequency consistency (перед bulk_upsert сверять target.frequency с фактической частотой добавляемых точек).

docs/plan.md создан — plain текстовый список того, что осталось доделать. Без маркеров и форм.
