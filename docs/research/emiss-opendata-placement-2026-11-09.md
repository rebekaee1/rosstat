## 2. Куда что ставить (экран у каждой темы)

Что увидел на стенде (iPhone Air, страница региона, снимки `board/shots/r4d-1.png`, `r4d-2.png`): наверху «Цены в регионе» (карточки: значение, единица, изменение
к прошлому месяцу), ниже длинный ряд тематических списков карточек «значение · миниатюра тренда · изменение · год». Это подходит всему, что годовое или месячное.
Что не подходит: распределения (20 %-группы, 88 рядов по интервалам дохода), пирамиды (384 ряда пол × возраст), структуры (доли по источникам). Им нужен свой экран, а не 88 карточек.

4. Пенсия к прожиточному минимуму (31437). 5. Суммарный коэффициент рождаемости (31517).

### Что скрыть как служебное
Ряды «квартал к отчётному году» и «на конец квартала к концу IV кв.» при показателе «к соответствующему кварталу» (три вида одного индекса в 30925 — оставить один);
«нарастающим итогом» в виде отдельных рядов (считать на странице); СНС-поправки («статистическое расхождение», «изменение запасов»); «оперативные данные»;

периоды в будущем (30957: до 2027-12).

### Что не брать и почему
98 наборов, у которых последний период раньше 11.2024 (кроме единственных на тему: см. пробелы ЖКХ/здоровье — оставить как архив «до 2018»); повторы одного ряда под разными id
(41627–41633 «впервые признанные инвалидами»: 935 значений ×4); исторические территории («Сибирский ФО (до 03.11.2018)», «Южный ФО (до 29.07.2016)»,
«Эвенкийский АО», «Тюменская область (кроме ХМАО и ЯНАО)») — мапа сайта их не знает, пропускаем с записью в отчёт.

### Как называть по-человечески
Правила: убрать скобки с годами и «в хозяйствах всех категорий» (оставить в пояснении); «Общие коэффициенты рождаемости» → «Рождаемость, на 1000 человек»; «Среднемесячная номинальная начисленная
заработная плата работающих в экономике по обследуемым видам деятельности» → «Средняя зарплата»; «Величина прожиточного минимума» → «Прожиточный минимум»; вид показателя — в подпись
(«первичный рынок», «все типы квартир»), единица — из измерения 30611 (рубль → «₽», процент → «%»). Названия держит таблица переименований рядом с загрузчиком; тексты — без слов «ЕМИСС», «dataGrid», «oid».

## 3. Решения, которые нужны от владельца (не блокируют сбор)
1. **Квартальный слой.** 487 рядов / 0,56 млн точек (цены на жильё, доходы, прожиточный минимум, пенсии) не ложатся ни в `region_data` (год), ни в `region_monthly_data` (YYYYMM).
   Предложение: `region_quarterly_data` (период YYYYQ), по образцу monthly; пока слоя нет — квартальные ряды не грузим. Запасной вариант для «цен на конец периода»: брать IV квартал как годовое значение (нельзя для индексов за период).
2. **Нарастающий итог** (ДТП, преступления, зарплата январь–март): брать только месячные ряды; где есть только нарастающий — загрузчик может вычесть предыдущий месяц, но это расчёт, а не данные источника. По умолчанию не делаем.
3. **Срезы «на 1 января»** (население, пенсионеры): хранить с годом среза и пометкой в ноте; сайт сейчас ждёт «на конец года». Загрузчик ставит код `…-1jan`.

## 4. Спецификация загрузчика (без запуска на базах)

Вход: `grid/{id}.json.gz` (+ `pages/{id}.json`). Ответ — `lines` (измерения строк), `cols` (`3` год, `33560` период), `payloads[].results[]` (строки).

1. **Строка** = сочетание значений измерений в `dim<oid>` (значения — названия, не oid). **Ячейка** — ключ `dim<год>_<oid периода>_d…_i…`; значение в ru-локали («1 234,5»; «-», пусто → пропуск). Запросы режутся по годам, поэтому одна строка приходит в нескольких ответах — сливать по ключу.
2. **Территория** — первое из измерений `57831` (ОКАТО редакции Росстата), `30628`, `3301`, `36175`. Название → slug: `emiss_dimnames.json` (+ `emiss_okato_31448.json` по oid). Строка «Российская Федерация без учета новых субъектов (с 01.01.2023)» → `russia` с 2023 года;
   «Российская Федерация» → `russia` до 2023 (дубль после 2023 отбрасывается — как в `emiss_regional_parser`). Нет территории → `russia`. Неизвестные названия (исторические округа, «кроме АО», районы) — не грузить, считать в отчёт `skipped_regions`.
3. **Ряд** = все измерения строки, кроме территории, периода, года и единицы (`30611`): «Виды показателя», «Типы квартир», ОКВЭД… Код: `emiss<id>[-<транслит значений>-<crc32>][-q|-1jan|-1st]`, ≤ 96 знаков (как `region_indicators.code`); crc гарантирует уникальность после усечения. Единица — из измерения 30611 строки.
4. **Период** (`33560` на странице показателя): месяц → слой `monthly`, ключ YYYYMM; «I–IV квартал» (в т. ч. «(предварительные данные)») → `quarterly`, YYYYQ; «значение показателя за год», «январь-декабрь», «на 31 декабря» → `annual`, год;
   «на 1 января» → `annual` с суффиксом `-1jan`; «на 1 <месяца>» → `monthly` с `-1st`; «январь–…», «9 месяцев», полугодия, «16 числа», «на 30 июня» → не грузим (`other`). Неизвестное название — `?`, не грузим и считаем.
5. **Слои**: annual → `region_data(year)`, monthly → `region_monthly_data(month)`, quarterly — ждёт решения 1. Идемпотентность: `INSERT … ON CONFLICT DO UPDATE` по (indicator, region, period); ключ точки в памяти уникален.
6. **Показатель региона**: `region_indicators` = код, раздел (из таблицы выше), название после переименования, единица, `note` («Источник: Росстат, ЕМИСС №{id}. Данные с {2023} без новых субъектов»), `source_sheet='ЕМИСС, {id}'`, `frequency` (monthly для месячных, иначе null).
   Отсев на входе: ряд без точек; < 3 значений; единственная территория (кроме Россия-карточек); последний период старше 2 лет без пометки «архив».
7. **Свежесть и пересмотр**: `catalog.json.data_date` — дата обновления набора, сравнивать со сборкой; повторно качать только изменившиеся. Росстат пересматривает прошлые периоды — писать всё окно, не только новый месяц.
8. **Контроль перед боевой загрузкой**: тест формата (грузится ли `__count` = числу строк), сверка трёх рядов с сайтом ЕМИСС вручную, `skipped_regions` в отчёте, `check-all.sh`.

Прототип: `build_series(grid, page)` → `[Series(code, name, unit, layer, qualifiers, points{(slug, period): value}, skipped_regions)]`.
Прогнан по всем 312 скачанным наборам без падений (≈45 с): 8757 рядов, 8,27 млн точек; чаще всего пропускаются исторические территории и «кроме АО». Тесты (`python3 -m pytest scripts/emiss/`): 7 проверок на урезанных срезах реальных ответов 30925 (кварталы), 57824 (месяцы + нарастающий итог), 31517 (годы), 31548 (срез на 1 января).

## 5. Неизвестное и следующий шаг
- Не проверено глазами на сайте: как карточки выдержат ряды с 369 видами деятельности (нужен выбор вида; ответственность за экран — R4-A/соседи по зоне региона).
- Названия ведомств по ИНН: расшифрованы по составу наборов, каталог их не называет (Росстат 7708234640, Банк России 7702235133 — по составу; остальные — предположение).
- 22 «похожих на региональные» набора сверять с `indicators.json` руками (аналоги: `realnye-denezhnye-dohody`, `granitsa-bednosti`, `summarnyy-koeffitsient-rozhdaemosti`).
- Следующий шаг: допробить сборку по ЖКХ, образованию, здоровью, труду; потом одним пакетом решить квартальный слой и грузить на стенд.
