Подтверждение, что время в UTC: прогноз недельной инфляции создан 2026-09-30T17:07:02, то есть после бюллетеня (14:36 GMT), что при местном времени МСК невозможно; плановый слот ETL 20:00 МСК = 17:00 UTC. ## 8. Ограничения

- **Один снимок.** Все данные получены за 22 минуты 05.10.2026; одиночные значения не показывают регулярность. Задержки измерены на публикациях 11.09, 18.09 и 30.09 и не равны средней задержке за месяцы.
- **`Last-Modified` — верхняя оценка.** Файл выкладывают раньше официального выпуска; от слота 19:00 МСК наши задержки были бы короче, а у roschart, возможно, тоже (на сколько — не подтверждено).
- **Наше время загрузки — верхняя граница** по метке пересчёта прогноза (`created_at`); для ставки и курса прогноза нет, поэтому задержку не измерил. В API нет публичной метки последней успешной загрузки.
- **TE:** читались только шесть публичных HTML-страниц (обзор страны, ставка, ИПЦ, ВВП, безработица, M2); ряды не выгружались, формы не заполнялись; Cloudflare и 403 не встретились. Не открывал страницы «Currency» и «Wages» (лимит 5–6 страниц): курс и прогноз курса, а также зарплата — только из обзора. Начало истории взято из поля `temporalCoverage`; время реальной публикации значений у TE снаружи не видно (слоты календаря — плановые). На Wayback Machine снимка страницы M2 за 15.09–05.10 нет, поэтому лаг M2 у TE не подтверждён.
- **roschart:** 23 запроса к API и страницам, паузы 3 с; регистрации, ключей и входа не было; значения из xlsx сверены с их набором JSON. Годовая зарплата 2025 (91 495 ₽) и безработица 1,7 % (2025) по Росстату не сверены (в файле `tab2-zpl` только помесячные данные).
- **Что не сверено глубоко:** история ключевой ставки (46 дней), курса (10 дней), недельной инфляции (2 недели), безработицы (источник — PDF, только последние два значения). Годовая зарплата Татарстана 2024 года у нас (75 764) совпадает с 2024 у roschart, но к первоисточнику напрямую не привязана (простое среднее двенадцати месяцев 2024 года по файлу — 75 429; годовая цифра Росстата считается с весами).
- **Календарь:** сентябрьский ИПЦ ещё не вышел (слот TE 09.10), недельная инфляция за 29.09–05.10 выйдет 07.10; замер стоит повторить после этих событий.
- **Apex-хост:** запрос `forecasteconomy.com/russia/indicator/cpi-yoy` через Python вернул то же русское тело и `canonical` на `ru.`, а запрос через curl — `content-language: en` (другой ETag). Причину не исследовал (вопрос SEO/i18n, вне задачи); на сопоставление данных это не влияет (значения берутся из API).
- **Правила:** прод по ssh не использовался; репозиторий не менялся, кроме этого файла; commit/push/deploy не выполнялись.
