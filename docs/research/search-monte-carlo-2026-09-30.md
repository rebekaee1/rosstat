названия. Хорошая локальная фильтрация уже загруженного списка не означает
такое же качество глобального retrieval. Предыдущее **197/201** относится
к настроечному корпусу и сохраняется как датированное свидетельство,

## Global API: исходный автоматический счёт

Для точного кода gold требует его идентичности и явной географии/года;
для названий допускается тот же код либо одинаковое нормализованное
имя/частота. Фрагменты допускают несколько подходящих результатов.
Для semantic groups автоматика проверяет **тему по словам**, не строгое
экономическое измерение; это ограничение зафиксировано до запуска.

Всего raw oracle score **579/1 000**, top-1 **556**, any@100 **591**,
пустых ответов **393**, HTTP errors **0**. Эти доли не являются точностью

Следовательно, проблемы не объясняются только тяжёлыми искажениями.

## Границы gold и независимое прочтение

Keyword availability witness оказался недостаточным: упоминание рождения
в разрезе безработных не является рядом рождаемости; Government Consumption
не заменяет Household Consumption; электроэнергетические мощности не
доказывают производительность труда. Поэтому **393 пустоты нельзя объявить
393 потерями реально нужных данных**, а semantic scores — точной
семантической правильностью. Ошибки corpus/oracle сохраняются отдельно;
исходный score и gold не переписаны ради улучшения результата.

Смысловая разметка проверяется независимо по frozen bank boundaries,
названию, единице и методологии. Подвыборка заранее задана: 60 nonempty
semantic cases, 12 empty semantic cases и 12 catalogue failures по
SHA256(case id). Строгая мера (flow/stock, mean/median, index/rate), тема
и наличие подходящего witness различаются. Это ручной audit subset,
не полная разметка всех 1 000 случаев.

Дополнительно независимо выбраны **10 вопросов с проверенной подходящей
мерой**: зарплата, реальная зарплата, торговый баланс, ипотечная/кредитная
ставка, Brent, добывающая промышленность, урожай, consumer confidence,
миграция. Все десять естественных запросов дали пустоту. Отдельная
diagnostic code query нашла девять целей первой строкой; regional grain
цель найдена на позиции 55 без заданного региона. Эти pairs доказывают
конкретные провалы языка при наличии данных, но не дают общей visitor
accuracy и не подменяют frozen Monte-Carlo метрики.

В raw summary сохранены descriptive Wilson 95% и 2 000 cluster bootstrap
повторов по source target/semantic group. Для точного слоя bootstrap
**70,85–79,26%**, для фрагментов **79,90–89,66%** при условиях генератора.
Wilson предполагает binomial sampling; формула сверена с
[NIST](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm).
Зависимые перефразировки и ошибочный oracle ограничивают интерпретацию.
У слоя без успехов обычный bootstrap даёт вырожденный [0,0], поэтому
его нельзя объявлять нулевой вероятностью успеха на других запросах;
Wilson для 0/100 даёт верхнюю границу около 3,70% только при iid допущении.

## Локальные поля и конкретные дефекты

Независимый frontend корпус заморожен до вызова matcher: **850** случаев
по реальным adapted metadata и sampled eligibility pools, **843 прошли**.
По 170 exact names/codes/short words/single-edit случаев — все прошли;
раскладка **163/170**. Дополнительно controls **20/20**, actual-observation
literal table fixtures **123/123**. Это matcher/pool-adapter испытание,
не проверка всех серверных serializers или native browser journeys.

Шесть layout failures вызваны `RegionsHome.normalize`, удаляющим знаки
раскладки: например, «область» → `j,kfcnm` → `j kfcnm`. С raw query тот
же matcher/pool находит результат. Ещё «хлебных» → `[kt,ys[` не проходит
условие трёх подряд букв для layout fallback. Диагностика выполнена
после основного run и не использована для изменения source/score.

Подтверждённые backend примеры: `bea-sainc7n-1000 Wisconsin` трактует
`1000` как год; `fuel-ai95-eop-quarter` как неподдерживаемый конкретный
период; имя области «без автономного округа» теряет уточнение. В английском
вопросе trade balance служебные слова `is`/`it` дают страны Iceland/Italy
и конфликтуют с явно заданной Russia. Эти ошибки должны быть устранены
отдельно от расширения semantic ranking; новая нейросеть их сама не
доказывает исправленными.

## Следующее проверяемое действие

Разделить literal identity и смысловой запрос до парсинга даты/географии;
сохранить специфичность nested territories, исправить country-code/служебные
слова и layout preprocessing. Затем отдельно спроектировать понимание
разговорных понятий/вопросов с независимым экономическим gold. После любой
подстройки этот корпус станет regression-набором; следующая оценка требует
новой закрытой выборки. Текущий audit не внёс исправления, push или deploy.
