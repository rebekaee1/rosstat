## ForecastEconomy

`ForecastEconomy-cards.pdf`:58 страниц (обложка+57 макетов), полный текст
прочитан, все страницы отрендерены Poppler и просмотрены контактными листами.
`ForecastEconomy-screens.pdf`:36 страниц, полный текст и все растровые страницы
просмотрены. Прочитаны также README, manifest и saved responsive QA пакета
`~/Documents/ForecastEconomy-Images/2026-09-21/approval-pack`.

Пакет раскрывает 36 редакционных тем и21 дополнительных аналитических формы:
линия, ступенчатая ставка, нулевая база столбцов, rank, scatter, сезонная
heatmap, состав M2, годовой факт, неполный год, факт/прогноз, отрицательные
значения, waiting/null, возрастная пирамида, карта/распределение. Обложка и
README явно отделяют тематические макеты от категорий БД и семантической
приёмки всех мировых рядов. Визуально просмотрены отсутствие значения вместо
нуля, открытая история/период/единица/источник/бренд, отделение прогноза, карта
и экранные формы. Малые подписи не выдаются за повторную числовую приёмку.

Экранный альбом показывает мобильный читаемый график отдельно от художественной
карточки, desktop context links, навигацию, таблицу/методологию и CSS viewport
от320 до3440px. Это эмуляция desktop engines; PDF не устанавливает physical
iPhone/Samsung/Safari приёмку. Сохранённые294 responsive records прочитаны как
датированное свидетельство; заново не исполнялись.

**Статус:** прототипы21.09, а не текущие SSR/OG renderer. Тогда manifest имел
`all_approved=false`; позднейшее согласование и реализация отражены отдельно
в [дизайне24.09](../design/README.md), art-prompts и local acceptance. Пирамида,
scatter или сезонная heatmap в альбоме не доказывают готовность универсального
production адаптера для любой сущности. Текущие механизмы — `og_image.py`,
`seo_renderer.py`, frontend chartTheme/pageImage и explicit data adapters.

Важные сохранённые ограничения:85 региональных наблюдений vs84 геометрии в
снимке21.09; A18 условное empty состояние; A10 API не сообщает уровень доверия
интервала, «95%» не добавляется; SAAR-кварталы не суммируются; A04 использует
явно подписанный МВФ; AI рисует декор, числа/оси — детерминированные. Эти
исторические сведения служат условиями будущей проверки, не живыми счётчиками.

## Исключения

Два PDF результатов учебных/коммерческих команд и `Код.pdf` вычислимой модели
общего равновесия не описывают ForecastEconomy. Заголовки/первые страницы и
relevance scan полного извлечённого текста подтверждают другое назначение;
в них нет ссылок на FE. Они сохранены без изменения, исключены из состава
основной платформы и не помечены полным содержательным разбором. Связь в
старом чате сама по себе не делает любой внешний файл документацией проекта.
