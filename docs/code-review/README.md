# Доказательства содержательного разбора

- `reviews.jsonl` — рецензии файлов: SHA-256, диапазоны чтения, назначение и элементы. Актуальность проверяет `scripts/audit-code-documentation.py --check`.
- `coverage.json` — результат проверки источников и рецензий; `javascript-symbols.json` — отдельный Babel-инвентарь именованных определений.
- `validation.json` — финальные проверки, числа тестов и явно непроверенные сценарии.
- `probes.json` — изолированные проверки HTTP fallback/default timeout и retention; без сети и БД.
- `baseline-c9/` — подробные вспомогательные каталоги первого полного прохода на `c9c2d95`: декларации frontend, imports, сообщения, ресурсы данных, 177 seed-записей и зависимости MCP. Они сохраняют исходный срез; более поздние изменения описаны в текущем `reviews.jsonl`, эти каталоги не объявляются свежими автоматически. Проверка схемы и dependency metadata не означает аудит всех значений данных или исходников сторонних пакетов.

Этот каталог и генерируемый `../code-review.md` исключены из входного scope проверки во избежание рекурсивного хеширования самой рецензии. Скрипты проверки, шаблон просмотрщика, архитектура и остальные исходники входят в scope. Полный явный список исключений находится в `coverage.json`.
