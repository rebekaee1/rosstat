# ForecastEconomy — реализация утверждённого дизайна

24 сентября 2026. Локальная реализация в текущей версии проекта; публикация на
сервер и push намеренно оставлены после просмотра владельцем.

## Что является общей системой

Основной React-сайт, серверные быстрые страницы и PNG используют Manrope
(кириллица, локальный файл с OFL), pearl `#EEF0F4`, ink `#202A3C`, champagne
`#AD8A48`, ice `#CAD8E5` и blue `#6B8299`. Логотип F, название forecasteconomy и
домен согласованы между оболочкой, карточками и превью. Слои стекла имеют
непрозрачную основу для читаемости; blur ограничен поверхностями. Графики
показывают домен под визуализацией; числа не анимируются от нуля.

Основные механизмы: `frontend/src/styles/`, `chartTheme.js`, `Brand.jsx`,
`pageImage.js`; на сервере — `og_image.py`, `seo_renderer.py` и специализированные
SSR-адаптеры. Новый показатель получает оформление через эти механизмы, без
ручного создания отдельной картинки для каждого URL.

## Инфографика и иллюстрации

17 тематических растровых иллюстраций служат декором. Числа, даты, подписи,
графики, источник и бренд рисуются программно из наблюдений, а не генерируются
нейросетью. Поддержаны временной ряд, ступенчатая ставка, столбцы изменения,
рейтинг, сравнение, обзор KPI и трёхгрупповая возрастная структура. Это реальные
адаптеры; 57 ранее согласованных прототипов не объявляются 57 независимыми
работающими типами данных. Например, возрастно-половая пирамида требует
соответствующей матрицы; три возрастные группы не выдаются за пирамиду.

Широкий PNG — 1200×630, портретный — 1080×1350. SSR `<picture>` выбирает
портретный вариант на мобильном экране. Сохраняются запрошенный период,
реальные разрывы ряда, дробные значения, единицы, полное название и источник.
Длинный заголовок уменьшает декоративную область, а не обрезает содержание.
Рендер и кэш общие: не требуется заранее генерировать миллионы PNG.

Экспорт подборки с локальными реальными данными:

```sh
docker compose exec -T backend python /app/scripts/export-design-gallery.py --out /tmp/design-review-cards
mkdir -p output/design-review/cards
docker compose cp backend:/tmp/design-review-cards/. output/design-review/cards/
node scripts/build-design-review.mjs
python3 -m http.server 3080 --bind 127.0.0.1 --directory output/design-review
```

Пакет содержит 124 PNG: 31 сценарий × RU/EN × широкий/портретный формат,
включая самые длинные названия из локальной базы. Отдельно — 17 иллюстраций
и 312 снимков страниц/графиков финальной адаптивной проверки.

## Поисковый вход и переход к инструменту

Быстрая страница отвечает на конкретный запрос без ожидания JavaScript:
значение/период, содержательная картинка, таблица, контекст. Продолжение ведёт
на соответствующий интерактивный экран и `#chart`, с сохранением года.
Логотип ведёт домой, Россия — в российские регионы. Источники в интерфейсе
ведут к соответствующей странице ForecastEconomy; исходная организация и
официальный URL сохраняются в структурированных данных. Локальная проверка
не отправляет посетителя на внешний сайт поставщика данных.

## Обнаружение страниц и изображений

В sitemap входят существующие публичные canonical URL; популярность,
старый год и принадлежность к curated-набору не являются фильтрами.
Редиректы, отсутствующие наблюдения и недействительные даты не становятся
индексируемыми страницами. Единый диапазон четырёхзначных лет — 1000–9998,
но страница существует только при наличии данных. Пустые ряды США дают 404;
профиль не предлагает неработающий переход.

Изображение связано с документом через видимый `img`/`picture`, описательный
alt, `og:image`, `ImageObject` и `image:loc` в sitemap. Sitemap указывает URL
изображения без его предварительной генерации. Индексация и выбор картинки
поисковиком не гарантируются. IndexNow сообщает об изменениях; он не заменяет
sitemap и не является массовой гарантией включения в поиск. Имеющийся
ограниченный дневной обработчик истории сохраняет курсор и поведение при 429.
В этом проходе внешних массовых отправок не выполнялось.

Локальный sitemap от 24.09.2026: **1 847 073 URL**, 198 секций, 0 ошибок,
один опубликованный origin. `apex_locale_en=false` оставлен как есть.
RU/EN проверяются отдельно; `?preview_locale=en` — noindex-превью, а не
переключение production-доменов. Эти числа не являются числом страниц,
фактически включённых Google или Яндексом в индекс.

Официальные основания: [Google Images](https://developers.google.com/search/docs/appearance/google-images),
[создание sitemap](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap),
[image sitemap](https://developers.google.com/search/docs/crawling-indexing/sitemaps/image-sitemaps),
[мобильная индексация](https://developers.google.com/search/docs/crawling-indexing/mobile/mobile-sites-mobile-first-indexing),
[Core Web Vitals](https://web.dev/articles/top-cwv).

## Проверка и следующий выпуск

Полный локальный сайт — `http://localhost:3000`, не Vite 5173. Проверка
охватывает семейства маршрутов, RU/EN, SSR/PNG/JSON-LD/API, разные viewport и
браузерные движки. Это выборка поверх общего кода, не обход каждого из
миллионов URL и не проверка физических моделей телефонов. Плотность экрана
и дюймы не заменяют CSS-ширину и пользовательский масштаб.

Сначала просмотр владельцем локальной версии; затем отдельный выпуск по
`docs/workflow.md` с явно выбранным SHA, миграциями, публикацией ассетов раньше
HTML, smoke обоих доменов и наблюдением ошибок. Локальные тесты не доказывают
поведение nginx/CDN, старых клиентских кешей или поисковых ботов на сервере.
