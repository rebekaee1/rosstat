## Производительность и границы

`performance-lab.json` — одиночные локальные замеры в новых browser context, без сетевого/CPU throttling, с неопределённым состоянием серверного кэша. Это не полевые Core Web Vitals и не проверка INP. Ответ 401 `/auth/me` ожидаем для гостя. Начальный замер выявил CLS страницы Германии 0.409. Повтор с источниками сдвига подтвердил причину: короткий skeleton показывал футер в первом экране, затем каталог вытеснял его. Коммит `5f43359` резервирует viewport во время загрузки. На пересобранном frontend CLS изменился с 0.525241 до 0.001636, сдвиги футера исчезли; остался небольшой сдвиг navbar. LCP двух единичных локальных запусков 564 и 796 мс, статистическое сравнение по ним не делается. Артефакты: `performance-country-before.json`, `performance-country-after.json`; 14 целевых frontend-тестов пройдены. Основная галерея сохраняет снимки завершённого интерфейса, который эта правка состояния загрузки не меняет.

Локальный sitemap: 1 847 073 URL, 198 секций, 0 ошибок, один origin. `apex_locale_en=false` сохранён; английский preview не индексируется.
