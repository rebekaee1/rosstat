# Локальная галерея приёмки

```sh
node scripts/build-design-review.mjs
python3 -m http.server 3080 --directory output/design-review
```

Открыть `http://localhost:3080`. Production app/router не меняются. Каталог
`output/design-review/` игнорируется Git и целиком переносится/архивируется:
HTML, изображения, Manrope с лицензией и промпты не требуют внешней сети.
Кнопка «На сайте» ведёт на соответствующую страницу `localhost:3000`.

## Входы

- `output/design-review/cards/manifest.json`: массив либо `{ "entries": [...] }`;
  поля записи — `id`, `title`, `theme`, `locale` (`ru/en`), `format`
  (`wide/portrait`), `file`, `path` (URL страницы). `file` может быть относительно
  каталога manifest или корня репозитория. PNG создаёт реальный OG-рендерер;
  builder не рисует экономические данные.
- `docs/design/local-acceptance/{stage}/browser.json` или `all.json`: снимки из
  `browser[].screenshot` (вид «Страница») и `browser[].chartScreenshot`
  (вид «График»). Каждый обрабатывается независимо; оба сохраняют URL,
  язык и CSS-ширину исходной проверки (`width`, иначе `document.viewport.width`).
  Число «снимков сайта» включает оба вида, это не число уникальных страниц.
  Отчёты без непустого массива `browser` не участвуют в выборе этапа.
  По умолчанию выбирается новейший этап с `final` или
  `after-build` в имени; если таких ещё нет — последний доступный небазовый,
  с явной отметкой «предварительный этап».
- Иллюстрации автоматически собираются из `frontend/public/art/quicklinks/`;
  промпты — из `docs/design/art-prompts/*.json`. В переносимую копию промптов
  не включаются абсолютные пути исходных файлов. При каждой сборке также
  копируется `forecast-glass-reconstruction.md`: в просмотре брендовой
  иллюстрации он явно подписан как реконструкция, а не исходный промпт.

```sh
node scripts/build-design-review.mjs --stage final-browser
node scripts/build-design-review.mjs --watch
```

`--watch` проверяет входы каждые 3 секунды и пересобирает пакет после появления
manifest/нового этапа. После сообщения об успешной сборке обновить страницу.
Повторный запуск безопасен: исходные карточки и manifest не удаляются.
Отсутствующие изображения пропускаются и перечисляются в результате сборки;
данные пакета доступны в `gallery-data.json`.

Первый экран показывает подборку карточек и сайта. Фильтры переключают весь
каталог; нейтральные иллюстрации доступны при любом языке. Во вкладках «Сайт»
и «Подборка» можно выбрать «Страница»/«График» и точную ширину экрана
(например, 320, 390 или 768 CSS px; список строится по имеющимся снимкам).
Выбор вида или ширины в подборке оставляет только соответствующие снимки
сайта. В карточках и иллюстрациях эти два фильтра отключены: размер OG-файла
не считается шириной экрана. Графики в превью показаны целиком.
В просмотре есть
полный оригинал, масштаб 100%, ссылка на страницу и промпт; Esc закрывает,
стрелки ←/→ переключают изображения.

## Решения по изображениям

Открыть изображение → «Утвердить», «Доработать» или «Снять решение».
Необязательный комментарий сохраняется при вводе; снятие решения сохраняет
комментарий. Статус виден на карточке и доступен в фильтре «Статус решения».
Решения хранятся только в `localStorage` этого браузера и адреса галереи
(тот же протокол, host и порт), без сервера и внешней отправки.

Ключ состоит из устойчивого `item.id` и SHA-256 байтов полноразмерного
изображения. Перестановка записей или новая сборка не снимает решение, а
изменение картинки требует нового утверждения. Старое решение остаётся
привязанным к старому файлу и не применяется к новой версии.

«Скачать решения JSON» выгружает весь текущий пакет, включая изображения
без решения, комментарии, дату решения, URL и SHA-256. Фильтры не ограничивают
экспорт. Для передачи результатов или переноса между браузерами сохранить
этот JSON; автоматического импорта и публикации нет. Если браузер запретил
`localStorage`, галерея явно сообщает об этом и позволяет скачать решения
из текущей вкладки.
