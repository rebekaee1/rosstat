# Локальная проверка доступности и адаптивности

Дата: 2026-09-24. Проверена рабочая версия frontend на `http://127.0.0.1:5173`
в Chromium / Playwright, высота viewport — 900 px. Это ограниченная проверка
конкретных сценариев; не сертификация WCAG и не приёмка production.

## Подтверждённые исправления

- Панель ИПЦ переносит CSV, Excel, PNG, справку и переключатель прогноза на
  следующие строки. На 320 px переключатель прежде заканчивался на x≈405 и
  обрезался; теперь все элементы доступны без скрытия кнопок.
- Подпись исходной суммы в калькуляторе инфляции размещается внутри графика.
  На 320 px строка `100 000 ₽` прежде заканчивалась на x332; после исправления
  она занимает x214–268 внутри SVG x37–283.
- Tooltip демографии больше не обрезается контейнером графика. Длинные подписи
  переносятся, числовые значения не сжимаются; ширина ограничена 280 px и
  доступной шириной экрана. На узком графике tooltip использует также место
  под осью Y; на широком следует за указателем.
- Проценты в полосе возрастной структуры получили светлую подложку и тёмный
  текст. Прежний белый текст 11 px давал только 3,07:1 на champagne и 3,77:1
  на blue; старое сочетание удалено.

Tooltip: 28 сочетаний размера × языка × режима × ввода, 84 проверки позиции.
Для каждого проверены видимость, количество числовых полей (4 абсолютных,
3 процентных), реальные границы текстовых фрагментов, viewport и отсутствие
горизонтального скролла. Touch-сценарии используют касание также для кнопок
режима; не смешивают синтетический mouse-click с последующим touch.

## Границы проверки

- Проверки выполнялись на актуальных локальных данных, без подмены значений
  на демонстрационные. Отдельно проверялась геометрия текста, а не только
  `document.scrollWidth`: внешнее обрезание способно скрыть переполнение.
- Проверены целевые клавиатурные действия; полный обход всех экранов,
  VoiceOver, реальное iOS/Android-устройство, увеличение текста и полный
  аудит контраста всех компонентов в этот проход не входили.
- Общая проверка production-сборки на порту 3000 проводится отдельно.
  Локальный Vite smoke её не заменяет.
- ESLint для `DemographicsPage.jsx`, `IndicatorChartSection.jsx` и
  `CalculatorPage.jsx` завершился без ошибок.
