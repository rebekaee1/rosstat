### `Nedel_ipc.xlsx` — 110+ товаров × недели

**Сейчас**: взвешенный CPI по продкорзине → один `inflation-weekly`. После deep dive 2026-05-12 (см. ниже) **169 из 170 точек = подлинные bulletin'ы Росстата** (Wayback + central-news), 1 точка осталась XLSX-приближением.

**Источниковая глубина (deep dive 2026-05-12, обновлено)**:

- Live `Nedel_ipc.xlsx` содержит листы 2022, 2023, 2024, 2025, 2026 (~4.5 года сырых product-индексов).
- `rosstat.gov.ru/central-news?page=1..65` — архив HTML-bulletin'ов «Об оценке индекса потребительских цен с N по M» от **2023-05-04** до today. Page=66+ возвращает пустую ленту.
- **Главное открытие 2026-05-12**: Wayback Machine CDX search `rosstat.gov.ru/storage/mediabank/*.htm` за 2021-2023 нашёл **174 уникальных URL** bulletin'ов. Проверка каждого через `_parse_bulletin_html` показала, что **weekly CPI bulletin'ы Росстат начал публиковать только в 2023 году** (январь). До 2023 года Росстат публиковал **monthly** «Об индексе потребительских цен в <месяц>», но **не weekly**. Самый ранний найденный weekly bulletin — 2023-01-09 (доступен через Wayback `web.archive.org/web/20230111175043/.../1_11-01-2023.html`).
- **2023-01..04 backfill через Wayback Machine**: 16 недель (с 2023-01-09 до 2023-04-24) восстановлены **подлинными** значениями Росстатовских bulletin'ов через CDX → Wayback `id_` content endpoint → `_parse_bulletin_html`. Заменили XLSX-приближение (расхождения до 0.12pp) точными числами.
- Bug fix: парсер раньше искал bulletinы только за `today.year` → 135 точек 2023-2025 в БД были XLSX-агрегатом. Расширили `bulletin_years = [2023..today.year]`, после backfill — все ~155 точек 2023-05+ это bulletin Росстата (`bulk_upsert WHERE value <> excluded.value`).

**Вывод**: Утверждение «бюллетени с 2003 года» — заблуждение. **Weekly CPI bulletin'ы Росстата физически существуют только с января 2023 года.** До 2023 — только monthly публикации, доступные через `ipc_05_2022.xlsx` и аналоги.

Возможности дальнейшего расширения:

1. **2023-05-02 (1 точка)** — остаётся XLSX-приближение, в Wayback CDX нет snapshot'а bulletin за эту неделю. Можно опционально подменить через external archives (Интерфакс, Коммерсант). **P2 — низкая ценность за усилие**.
2. **2020-2022 weekly** — Росстат **не публиковал** отдельных weekly bulletin'ов. Только сырые product-цены в `Nedel_ipc.xlsx` (~110 продов). Возможна **proxy-публикация** «недельный CPI (приближение по food basket)» с честным дисклеймером и cutoff 2020-01. Расхождение с monthly CPI до 3pp в кризисные периоды (март 2022). **P1 — value vs noise trade-off**.
3. **2003-2019** — не существует ни в каком открытом формате. Closed databases (Bloomberg, IMF IFS) опираются на reuters-streaming а не Росстат.

**Пропущено в самом файле**:


| Категория                                                                                        | P                                                    |
| ------------------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| Per-product еженедельные индексы (бензин, хлеб, яйца, сахар, лекарства, бытовая химия)           | 🟠 P1 — каждый из ТОП-30 = отдельный микро-индикатор |

## Замечания и trade-offs

- **Дубли с разными источниками**: e.g. PPI есть в `osn-*.pdf` (мы берём) И в `ind_*.xlsx` sheet `3.1` (XLSX, точнее). Стоит мигрировать на XLSX для надёжности — PDF-парсинг fragile.
- **IPI**: в `ind_*.xlsx` sheets `1.2 (1999-2013)` + `1.2 (2014-2026)` есть готовый MoM% и YoY% — потенциально проще наших chain-вычислений из `ind_baza_`*.
- **CPI**: в `osn-*.pdf` раздел 3.1 дублирует `ipc_mes_*.xlsx` — резервный канал.
- **Региональная аналитика**: `OkPopul_Comp`* + `innov-mp_1.xls` + `innov_*` дают разрез по 85 субъектам — это другой продукт (frontend region-picker), отдельный спринт.
- **Per-product CPI**: `ipc_spr` 753 товара — overkill для основной платформы, но `inflation-staples` (хлеб + молоко + яйца + бензин) интересный B2C-показатель.
