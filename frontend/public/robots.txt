# Clean-param — межсекционная директива Яндекса.
# Незначащие GET склеиваются с чистым URL. Disallow на те же параметры
# в секции Yandex не ставим: при конфликте побеждает Disallow.
# codes только на /compare. view — интерактивный срез, не канон.
# mode не склеиваем: в годовом документе он может выбирать другой ряд.
# year не склеиваем: на карте регионов ?year= входит в канонический URL.
# preview_locale не склеиваем: до языкового переключения он меняет язык,
# после переключения сервер перенаправляет на соответствующий хост.
# Лимит длины правила — 500 символов.

Clean-param: etext&ybaip&_openstat&openstat&clid&yandex_referrer&erid&from&ref&ref_src&source&mc_cid&mc_eid&igshid&_ga
