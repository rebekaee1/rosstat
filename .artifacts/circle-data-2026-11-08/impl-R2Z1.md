# R2-Z1 — страница региона и цены (телефон iPhone 17e)
Кадры: общая доска, board/shots/r2z1-*.png.
1. Блок «Цены в регионе» поднят над главными цифрами; у главных цифр свой заголовок (01-before, 01-after, 04-after).
2. Месяц вынесен из каждой карточки в подпись блока; на карточке только у отличающихся.
3. «Без перемен» вместо «− <0,1 %» (карточки и строки).
4. Короткий абзац в шапке региона.
5. «Все цены» в одну строку с названием блока.
6. Каскадное появление карточек цен.
7. Название карточки цены 14 px.
8. Баг: «Все цены» вело в тему «Транспорт»; теперь в «Цены и тарифы» (05-after).
9. В разделе цен группы идут первыми, годовые индексы после (06-after).
10. Строка показателя не вылезает за край экрана.
11. Группа цен порциями по 30.
12. Хаб: поле «Найдите свой регион» (07-before, 07-after).
13. Хаб: ₽ и % у каждого числа рейтинга (08-after).

Тесты: vitest src/pages, src/components/regions, src/styles зелёные; eslint по моим файлам чист. Полный src и eslint src целиком не гонялись.
Неизвестное: сравнения с прошлым годом и соседями в API нет (только prev_month). Ввод текста в поле региона на симуляторе не проверен.
