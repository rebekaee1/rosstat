# Clean-param — Yandex inter-section directive.
# Insignificant GET params glue to the clean URL. The Yandex group does
# not Disallow the same params: on conflict Disallow wins.
# codes applies only to /compare. view is an interactive slice, not canonical.
# mode is not glued: a year document may select a different stored series.
# year is not glued: on the regional map ?year= is part of the canonical URL.
# preview_locale is not glued: it changes language before cutover, then the
# server redirects it to the corresponding language host.
# Rule length limit is 500 characters.
